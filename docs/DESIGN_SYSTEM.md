# BookOnTime Design System

## Brand lock

Name: **BookOnTime**  
Tagline: **Book Before It’s Late.**

Approved logo concept: ticket + clock. Do not redesign it or make the brand train-specific.

## Visual language

- Clean, minimal, modern
- White-dominant with pale-blue surfaces
- Dark navy text
- Primary blue actions and icons
- Rounded cards, subtle borders and shadows
- Generous spacing
- Consistent icon family
- No excessive gradients, glassmorphism, neon colors, 3D icons or mixed icon styles

## Typography

Primary font: **Inter**.

Use clear hierarchy, readable body text, compact labels and accessible button text.

## Core colors

- Primary Blue: `#2563EB`
- Dark Navy: `#0F2747`
- Light Blue: `#EAF4FF`
- Pale Blue: `#F4F9FF`
- Background: `#FAFBFF` / white
- Success: accessible green
- Warning: accessible amber/orange
- Danger: accessible red
- Muted: slate gray

Small shade adjustments are allowed only for accessibility and state hierarchy.

## Responsive shell

Desktop primary navigation:

- Home
- Reminders
- Calendar
- Booking Rules
- Settings
- prominent `+ Add Reminder`

Mobile bottom navigation:

- Home
- Reminders
- Add
- Calendar
- More

More contains Booking Rules, Settings, Data & Backup, Install App and About.

## Required icon family

Categories: Train, Bus, Flight, Movie, Event, Sports, Darshan, Appointment, Registration, Accommodation, Custom.

Utilities: Home, Bell, Calendar, Clock, Rules, Settings, Search, Filter, Add, Edit, Duplicate, Delete, Share, External Link, Notification, Booked/Check, Warning, Import, Export, Install, Offline.

Darshan must be represented by a recognizable **Hindu temple/gopuram architectural structure**. Do not use a deity, person, church, mosque or generic religious icon.

## Key UI patterns

- Large countdown for the next opening
- Clear status chips with text plus color/icon
- Rounded, compact reminder cards
- Forms with progressive disclosure
- Booking opening datetime visually stronger than target/journey date
- Holiday/long-weekend warnings are contextual and non-alarmist
- Empty states are useful but not oversized marketing pages

## Dark mode

Support System, Light and Dark. Dark mode should be purpose-designed while preserving BookOnTime blue/navy identity; do not mechanically invert colors.

## Reference assets

Files under `design/reference/` are approved visual references. Use them for layout direction, logo, icon language, backgrounds, spacing and color consistency. Written specs override generated placeholder content inside images.

## Accessibility

- Semantic HTML
- Visible focus state
- Accessible form labels
- Sufficient contrast
- Approx. 44px+ touch targets
- Important status must not rely on color alone
- Screen-reader labels for icon-only controls

## Breakpoints to verify

360, 390, 430, 768, 1024, 1280, 1440 and 1920 px.
