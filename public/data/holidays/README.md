# Generated Holiday Data

Runtime holiday JSON belongs here. Core app functionality must not require an online holiday API.

Suggested layout:

- `IN/2026.json`
- `IN/2027.json`
- `IN/states/TN-2026.json`
- `IN/states/KA-2026.json`
- additional country/region files as needed

Baseline data should be generated by `scripts/generate-holidays.ts`; official/manual overrides should take precedence when supplied.
